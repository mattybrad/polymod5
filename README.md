# Polymod 5
### Polyphonic digital modular synth

A fifth(!) attempt at this ambitious but fun project where I attempt to create a (real, physical) modular/patchable synthesizer. I come back to this every couple of years as I get better at coding and PCB design, or when technology improves. This iteration will be in C++, hopefully using a Raspberry Pi Pico 2 with a DAC, because I've successfully used this setup for the most recent version of my drum machine, Drumkid. If it's not powerful enough, I'll look at other options.
